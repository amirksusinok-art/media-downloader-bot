# 🚀 Universal Media Downloader Bot

Универсальный и быстрый Telegram-бот для скачивания медиаконтента без водяных знаков со всех популярных платформ, постобработки видео (нарезка, скорость, сжатие, кружочки) и пакетной загрузки в дорогу.

## 🌟 Ключевые возможности

### 1. Поддержка популярных платформ
- **TikTok**: видео без водяных знаков в максимальном качестве + **фотокарусели** (скачивание всех слайдов альбомом и фонового трека).
- **YouTube**: Shorts и стандартные видео.
- **Instagram**: Reels и видеопосты.
- **X (бывший Twitter)**: видеоролики и GIF.
- **VK (ВКонтакте)**: VK Клипы и VK Видео.
- **Reddit**: видеоролики со склейкой звука (DASH).
- **Pinterest**: идеи, анимации и видео.
- **Twitch**: клипы со стримов.
- **Likee**: ролики без водяных знаков.

---

### 2. 🎛 Встроенный видео-комбайн (кнопки под каждым видео)
- 🎵 **MP3**: мгновенное извлечение аудиодорожки из любого видео.
- ⚡ **Скорость**: ускорение (`1.25x`, `1.5x`, `2.0x`) или замедление (`0.5x`).
- 🗜 **Сжать**: сжатие видео через H.264 с флагом `+faststart` (уменьшение веса до 60% без потери качества).
- ⭕ **В кружочек**: умное кадрирование в квадрат 1:1 и отправка в виде нативного видеосообщения Telegram (Video Note).
- 🏷 **Вотермарк**: наложение вашего никнейма или логотипа (`/watermark @канал`) в угол видео.
- 🌐 **Прямая ссылка для файлов >50 МБ**: если видео превышает лимиты Telegram, бот генерирует ссылку для скачивания напрямую в браузере!

---

### 3. 🏷 Водяной знак (`/watermark`)
- Задать текст/юзернейм: `/watermark @мой_канал`
- Включить авто-наложение на все скачиваемые видео: `/watermark auto`
- Отключить водяной знак: `/watermark off`

---

### 4. ✂️ Быстрая обрезка видео (`/cut`)
- Обрезка по ссылке:
  ```bash
  /cut 0:10 0:35 https://vt.tiktok.com/...
  ```
- Обрезка в ответ на любое видео: ответьте на видеосообщение командой `/cut 0:10 0:35`.

---

### 5. ✈️ Режим «В дорогу / Самолёт» (`/travel` или `/pack`)
- Отправьте боту несколько ссылок сразу или используйте команду `/travel`.
- Бот предложит выбрать желаемое качество:
  - 🚗 **Компактный (480p)** — экономия дискового пространства и трафика.
  - ✈️ **Стандартный (720p)** — идеальный баланс качества.
- Все ролики обрабатываются с кодеком `+faststart` (moov atom в начале файла), что обеспечивает мгновенное воспроизведение на телефоне даже при нулевом интернете в самолёте.

---

### 6. 🛡 Архитектурная стабильность и обход блокировок
- **Защита от перегрузки (Task Queue)**: ограничение параллельных задач FFmpeg (до 2 задач), что защищает сервер Render от падения памяти (OOM).
- **Поддержка `data/cookies.txt`**: стабильное скачивание с YouTube и Instagram без банов по IP. Достаточно положить файл куков в `data/cookies.txt`.
- **SQLite Кэш**: мгновенная отдача ранее скачанных роликов за 0.1 сек по `file_id`.
- **Inline-поиск**: в любом личном или групповом чате наберите `@botname <ссылка>` для отправки видео прямо в диалог.

## 🛠 Установка и запуск

### 1. Требования
- **Python 3.10+** (рекомендуется Python 3.12+)
- **FFmpeg** (должен быть установлен и доступен в PATH)

### 2. Клонирование и установка зависимостей
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd veb

# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows PowerShell)
.\.venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```
*(Или с использованием `uv`: `uv venv && uv pip install -r requirements.txt`)*

### 3. Настройка бота
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Откройте `.env` и вставьте ваш токен бота от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
MAX_FILE_SIZE_MB=50
```

### 4. Включение Inline-режима (опционально)
Чтобы бот работал в групповых чатах по вызову `@botname`:
1. Напишите [@BotFather](https://t.me/BotFather).
2. Выберите `/mybots` ➔ ваш бот ➔ **Bot Settings** ➔ **Inline Mode** ➔ **Turn on**.

### 5. Запуск
```bash
python main.py
```
